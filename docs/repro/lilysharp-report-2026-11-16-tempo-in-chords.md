# Lily# から Dettato へ（2026-11-16）: コードの行の中に `tempo` も書ける（REQUESTS 14）

表は [`REQUESTS.md`](REQUESTS.md)。頼みではなく知らせ。REQUESTS 13（[コードの行の `time`](lilysharp-requests-2026-11-16-time-in-chords.md)）
を入れたときに、オーナーの了承で同じ決まりのまま `tempo` にも広げた。

## 1. 書き方

Lily# master `ff599303a` から（次の版）。小節の頭（`|` の直後か、行の最初）に書く:

```
section C {
  chords harmony {
    G D/F# | Em Bm7 | tempo "rit." 4 = 54 C | D |
  }
}
```

- **効く範囲**: その小節から、次の `tempo` まで楽譜全体の速さ。ノートの行の途中の `tempo` と同じ。`time` と違い、
  section が変わっても元に戻らない（tempo はもとからそういう決まり。戻すときは `tempo 4 = 72` などをもう一度書く）。
- **紙**: その小節の上に速度表示を刷る（「rit. (♩ = 54)」）。言葉だけ（`tempo "rit."`）なら言葉だけ、
  `bare` を付ければ数は刷らずに鳴らす（`tempo "a tempo" 4 = 72 bare`）。
- **書けない所**: コードの後（小節の途中）に書くと `LYS1073`。`time` と同じエラー。
- **音と書き出し**: MIDI はその小節の頭から速さが変わる（その行を score に置いているとき）。MusicXML・LilyPond も
  同じ所に速さを書く。

## 2. 録音と一緒に鳴らすとき

録音と一緒に鳴らすときは、Lily# は楽譜の小節を録音の同じ番号の小節に伸び縮みさせて重ねる（`timeWarp`）ので、
`tempo` を書いても書かなくても、録音との重なりは変わらない。`tempo` が効くのは、楽譜だけで鳴らすときと、
紙に刷る速度表示。

## 3. Dettato での使いみち（案）

- `.dettato.json` の `bars` の長さから、途中で速さがはっきり変わる所（rit.、a tempo、曲の後半で速くなる所）が
  分かるなら、その小節の頭に `tempo` を書けば、楽譜だけで鳴らしたときも録音に近い速さになる。
- 今は曲の速さを先頭の `tempo` 1 つで書いている。小節ごとに細かく書く必要はない（録音と一緒なら `timeWarp` が
  合わせる）。書くかどうか、どれくらいの変化から書くかは Dettato の判断。

Lily# の側で、Dettato に変えてほしいことはない。
