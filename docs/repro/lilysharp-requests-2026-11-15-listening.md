# Dettato から Lily# へ（2026-11-15）: 録音を聴きながら直す（REQUESTS 4）

表は [`REQUESTS.md`](REQUESTS.md)。依頼 2（選んだ小節の原音を鳴らす。「今は作らない」）を、形を広げて出し直すもの。

## 0. なぜ出し直すか

**オーナーの希望（2026-11-15、Dettato のセッションで）:** 長年使っている Transcribe!（Seventh String）と同じ体験を Lily# で。
用途の中心はエレキベースの耳コピ。Dettato の読みは下書き（実録音でルート 87%・小節線 F 93〜95%）なので、直すには
「この小節は録音でどう鳴っているか」を何度も、遅く、高くして聴く道具が要る。Transcribe! は小節線を人が打つ所から始めるが、
Dettato の後なら小節線は引いてあり、人は外れた所とテンポの揺れを直すだけになる。

参考: https://www.seventhstring.com/xscribe/overview.html と、オーナーの使い方の説明（キー操作はページに書かれていない）。

## 1. Transcribe! の体験（オーナーの説明と公式ページ）

| Transcribe! | 何に使うか |
|---|---|
| 再生しながら **M** で小節、**B** で拍、**S** でセクションのマーカーを打つ。後から動かせる。名前とメモを付けられる | 小節へ飛ぶ、小節を繰り返す |
| 範囲を選び、その中のマーカーからテンポを計算する | 揺れる録音の、その部分のテンポ |
| 名前つきのループを何個でも保存・呼び出し | 難所を繰り返す |
| 速度 1/20〜2 倍（音高は保つ）、リアルタイム | 速いフレーズを聴く |
| 音高をセント単位で、最大 3 オクターブ。**音高を変えたら速度も同じ比で変える連動があり、オン・オフできる** | ベースを 1〜2 オクターブ上げて聴く。**古いテープの録音は伸びで速度と音高がずれるので、セント単位で戻す**（連動オンが、テープの速度を戻すのと同じ） |
| EQ、モノラル・カラオケ（位相反転で中央を消す） | 埋もれたベースを聴く |
| ショートカットは設定可能、フットペダル（3 つ踏み: 再生・停止、1 小節戻る・進む） | 手を楽器から離さない |

## 2. してほしいこと（優先順。形は Lily# とオーナーが決める）

1. **小節を押すと、その小節から原音が鳴る。** 範囲を選べばループ。同じ section が form で何度も鳴るなら最初の回（または今の再生位置に近い回）。
2. **マーカーを打つ・直す。** 再生中の M・B・S（プレビューにフォーカスがあるとき）、ドラッグで移動。打った所は近くの拍（Dettato が書く）へ
   吸い寄せる（オフにできる）。**人が打った・動かしたマーカーが正**で、印（人が確かめた）が付く。確かめていない小節線は薄く描く案。
3. **速度と音高。** 速度（音高は保つ）、セント単位の音高、オクターブ、**音高と速度の連動のオン・オフ**。
   連動オンは再標本化だけで済む（伸縮のエンジンが要らず、音が荒れない）。連動オフと、音高を保った速度変更には伸縮のエンジンが要る
   （候補: Signalsmith Stretch（MIT と記憶）、SoundTouch（LGPL）、Rubber Band（GPL か商用）。どれもライセンスと品質は Dettato 側では未確認。
   ベースを +1200 セントにしたときの音で選んでほしい）。
4. **範囲のテンポ。** 選んだ範囲のマーカーから bpm を出す。`.lys` の `tempo` に入れる手段があるとよい（テンポが途中で変わる曲は Dettato の C3）。
5. EQ、モノラル・カラオケ、ショートカットの設定。ペダルはキーを出す型ならそれで足りる。動画の表示、加工した音の保存は後でよい。

## 3. Dettato が用意するもの

| もの | 中身 |
|---|---|
| 復号した音 | webview の Chromium は AAC（mp4・m4a）を復号できないはず（未確認）。伸縮にも PCM が要る。Dettato は読むときに Media Foundation で復号し、エンコーダの無音を取り除いている（`x.dettato.json` の秒とサンプル単位で合う）ので、それを渡す。渡し方（wav を書く／求められたら返す）は相談 |
| 拍 | Beat This! の拍の時刻を `x.dettato.json` に足す。小節の中のカーソルを等間隔でなく拍で動かせる |
| 調律 | Dettato は読むときに調律のずれ（半音の ±1/2 まで）を測っている。それをセントで `x.dettato.json` に書けば、Lily# は音高の初期値に使える（テープの録音を A440 に戻す） |
| 読み直し | 人の小節線を渡すと、その上でコードを読み直す（人が触った線は動かさない）。`dettato` に入口を足す |

## 4. `x.dettato.json` を形式 2 にする（Dettato 側の案。SIDECAR.md は合意してから直す）

- 形式 1 は「読んだときのまま。誰も書き換えない」。形式 2 は **人が直してよいファイル**で、人の手が正。
- 足すもの: 小節ごとの `byHand`（人が確かめた）、`beats`（拍の時刻と `byHand`）、セクションのマーカー（form の何回目か。`.lys` の section の定義ではなく、
  録音の中で鳴る回）、名前つきのループ、`tuningCents`。
- 書くのは Lily#（マーカー・ループ）と Dettato（読み直し）。書く物の取り合いの決め方は相談。
- 速度・音高・EQ の今の値は、ファイルに書くか表示の状態にするか、Lily# が決めてよい。

## 5. 聞きたいこと

- 上の優先順でよいか。最初の版はどこまでか。
- 伸縮のエンジンの選び方、webview で AudioWorklet を使えるか。
- 復号した音の渡し方、置き場所（`.lys` の隣に大きな wav を置くのは避けたい）。
- 人が小節を足し消しして、Lily# の小節数とファイルの小節数が合わないとき（形式 1 では「鳴らさず知らせる」）。人が小節線を打てるなら、
  ファイル側を正にして `.lys` に小節を足す案もある。
